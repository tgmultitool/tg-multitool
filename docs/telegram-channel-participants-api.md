# Как получить список участников канала через Telegram API

Если нужно получить список участников публичного канала или группы программно, Telegram API даёт для этого метод - но с реальным ограничением, про которое важно знать заранее.

## Основной метод: GetParticipantsRequest

В Telethon это обёрнуто в удобный хелпер `iter_participants`, который сам разбивает запросы на страницы:

```python
async for user in client.iter_participants(channel):
    print(user.id, user.username, user.first_name)
```

Под капотом это вызывает `channels.GetParticipants` постранично - `iter_participants` просто избавляет от ручной пагинации.

## Реальное ограничение: предел в районе 10 000

Для больших каналов (не супергрупп с полным списком) Telegram API отдаёт не весь список участников напрямую, а ограниченное количество - примерно до 10 000 через обычный проход. Это задокументированное поведение API, не баг конкретной библиотеки.

## Обход через поиск по символам

Для каналов больше этого предела применяют приём: вместо одного общего запроса делают несколько запросов с фильтром по первой букве имени или username, через `aggressive=True` в Telethon:

```python
async for user in client.iter_participants(channel, aggressive=True):
    print(user.id, user.username)
```

Это не обходит ограничение Telegram, а уменьшает число участников в каждом отдельном запросе за счёт фильтрации, из-за чего суммарно удаётся собрать больше уникальных пользователей, чем одним проходом.

## Какие данные доступны, а какие нет

Через участников канала доступны: `id`, `username` (если открыт), `first_name`/`last_name` (если не скрыты настройками приватности), статус участника (обычный, админ, создатель). Номер телефона напрямую недоступен - он виден только если пользователь сам открыл его в настройках приватности для вас.

## Частые вопросы

**Можно ли получить весь список участников любого канала?**
Нет, зависит от типа канала и числа участников - у больших публичных каналов есть предел, описанный выше.

**Нужны ли права администратора для чтения списка участников?**
Для публичных каналов - нет, список участников (в рамках ограничения API) доступен и обычному участнику. Для закрытых групп - нужно быть участником группы.

**Можно ли получить список подписчиков канала, если я не состою в нём?**
Нет, для получения списка участников аккаунт должен сам состоять в канале или группе.

## Когда это нужно делать для многих каналов сразу

Разобрать список участников одного канала вручную по коду, который выше, реально. Когда нужно собирать аудиторию сразу с нескольких каналов, с фильтрацией и экспортом результата - это уже отдельная задача. В мини-приложении [TG Multitool](https://tgmultitool.com) модуль [«Парсер аудитории»](https://tgmultitool.com/modules/audience-parser/) делает это массово, с учётом того же ограничения API на уровне самого инструмента.
