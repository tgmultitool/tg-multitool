# Что такое СБ (спам-блок) в Telegram и как его распознать

Если Telegram-аккаунт внезапно перестаёт доставлять сообщения незнакомым
людям - скорее всего, сработал так называемый "СБ" (спам-блок), временное
ограничение Telegram на рассылку сообщений пользователям не из контактов.

## Что это такое

Технически это выглядит как ошибка `PeerFloodError` (код `PEER_FLOOD`) при
попытке отправить сообщение через `SendMessageRequest` человеку, который не
добавил вас в контакты. Telegram не присылает отдельное уведомление - узнать
об ограничении можно только по этой ошибке API либо через `@SpamBot`.

## Почему он срабатывает

Это публично известное поведение Telegram, без привязки к какому-то
конкретному сервису:

- новый или малоактивный аккаунт;
- высокая скорость сообщений незнакомым людям за короткое время;
- жалобы получателей ("Это спам").

## Как проверить вручную

Самый простой способ - написать `/start` боту [@SpamBot](https://t.me/spambot)
прямо из приложения Telegram. Бот сам сообщает, есть ли ограничение и на
сколько оно установлено.

## Пример на Python (Telethon)

То же самое можно сделать из кода - `@SpamBot` отвечает обычным текстовым
сообщением, которое можно распарсить программно:

```python
async with client.conversation("@SpamBot") as conv:
    await conv.send_message("/start")
    reply = await conv.get_response()
    print(reply.text)  # Telegram сам описывает статус/срок ограничения текстом
```

## Что реально помогает

Это тоже публично известные рекомендации, а не секрет какого-то конкретного
инструмента:

- переждать (ограничения обычно держатся от суток до месяца);
- снизить скорость и объём сообщений незнакомым людям;
- "прогреть" аккаунт обычной активностью перед рассылками;
- не делать массовые холодные рассылки с нового аккаунта.

## Автоматическая проверка по списку аккаунтов

Вручную писать `@SpamBot` удобно для одного-двух аккаунтов. Когда их
становится больше - проверка каждого аккаунта по очереди руками уже не
масштабируется. В мини-приложении [TG Multitool](https://tgmultitool.com)
есть модуль **"Проверка"**, который делает это сразу по всему списку
аккаунтов одной кнопкой.
